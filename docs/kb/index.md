# 知识库

知识库分区适合放不适合塞进教程的“专题文章”：FAQ、排错、最佳实践、概念解释。

## 目录

- [常见问题](/kb/faq) —— 模板使用中最常遇到的疑问。
- [让站点对 AI 友好](/kb/ai-ready) —— `llms.txt`、Markdown 副本、JSON-LD 与爬虫策略。
- [故障排查](/kb/troubleshooting) —— 构建、部署、样式与搜索问题。

::: tip 内容形态可以混用
同一个站点里既放线性教程，也放独立知识库文章，是这类模板的常见用法。侧边栏会按目录自动分开。
:::
