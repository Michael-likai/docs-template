# 使用指南

把 Folio 当成一个“文档站的脚手架”：内容、导航、主题和部署都在仓库里，没有黑盒服务。

## 从这里开始

1. [快速开始](/guide/getting-started) —— 装依赖、跑本地预览、打第一个包。
2. [写内容](/guide/writing-content) —— 目录约定、Frontmatter 与 Markdown 能力。
3. [定制站点](/guide/customizing) —— 改品牌、导航、首页和配色。
4. [部署上线](/guide/deploying) —— Cloudflare Pages 与 EdgeOne Makers。

## 适合什么内容

- **教程站**：线性章节 + 阅读路径 + 上一篇 / 下一篇。
- **产品文档**：分组参考、配置表、API 示例。
- **AI 知识库**：可被搜索、抓取和引用的结构化内容，附带 `llms.txt` 与逐页 Markdown。

::: tip 不知道从哪改？
先看 [站点配置](/reference/configuration) 和 [Frontmatter 参考](/reference/frontmatter)，两页覆盖了 90% 的日常修改。
:::
